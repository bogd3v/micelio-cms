# Documentation

The documentation is organised by who reads it. Find your reader in the table; each document is one kind: a tutorial, a how-to, a reference or an explanation.

| Reader                                  | Needs                                                   | Go to                                                                                                                                                                                                                                                                                     |
| --------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Someone deciding whether to use Micelio | What the CMS is and the shortest path to a running site | [`../README.md`](../README.md)                                                                                                                                                                                                                                                            |
| Site operator                           | Install, configure, upgrade, back up, every variable    | [`operate/`](operate/install.md): [install](operate/install.md), [configure](operate/configure.md), [upgrade](operate/upgrade.md), [backup](operate/backup.md), [troubleshooting](operate/troubleshooting.md), [verify the image](operate/verify-image.md)                                |
| Operator of one module                  | How a module behaves and what it needs                  | [accounts](ACCOUNTS.md), [analytics](ANALYTICS.md), [fediverse](FEDIVERSE.md), [rate limiting](RATE_LIMITING.md)                                                                                                                                                                          |
| Integrator                              | The frontend's API token and its permissions            | [`API_TOKENS.md`](API_TOKENS.md)                                                                                                                                                                                                                                                          |
| Site editor                             | Build pages and publish content in the CMS              | The [frontend's guide](https://github.com/bogd3v/micelio/tree/main/docs/guide)                                                                                                                                                                                                            |
| Contributor, human or agent             | Rules, structure and how a subsystem works              | [`engineering-standard.md`](engineering-standard.md), [`../AGENTS.md`](../AGENTS.md), [`architecture/`](architecture/overview.md): [CI pipeline](architecture/ci-pipeline.md), [drafts](architecture/drafts.md), [comments](architecture/comments.md), [testing](architecture/testing.md) |
| Security reviewer                       | How to report a vulnerability and the accepted risks    | [`../SECURITY.md`](../SECURITY.md), [`DEPENDENCY_RISKS.md`](DEPENDENCY_RISKS.md)                                                                                                                                                                                                          |
| Whoever asks "why is it like this?"     | The decision, the options and the cost                  | The ADRs live in the [frontend repository](https://github.com/bogd3v/micelio/tree/main/docs/adr), which records decisions that span both                                                                                                                                                  |

Documents that do not belong to one reader:

- [`engineering-standard.md`](engineering-standard.md): the rules every Micelio repository shares.
- [`../CONTRIBUTING.md`](../CONTRIBUTING.md) and [`../SECURITY.md`](../SECURITY.md): the terms of a contribution and how to report a vulnerability.
