# Pages

Moved from `CLAUDE.md` (#113); the text is unchanged.

`api::page.page` (i18n, draft and publish) builds landing pages from the section catalog of micelio's ADR 0005 §11 and ADR 0006: `sections` is a dynamic zone of the 14 `section.*` components in `src/components/section/` (plus their item parts and `section.link`). Fields are semantic; `variant` is an enum of the core's variants, the only visual choice. Drafts may be incomplete: required fields, item counts (`min`/`max`) and link formats apply on publish. `src/utils/page-sections.ts` (Document Service middleware) adds what the schema can't: a `post-list` with both a category and a tag, and a `scene` model that is not `.glb`/`.gltf`. Item components need their own `collectionName` when a section has the same name in plural (`testimonial` vs `testimonials`). `site-setting.homePage` is localized: each language points at its own version of the page. Only API tokens read pages (`src/migrations/page-permissions.ts` removes role permissions). `src/utils/rebuild-hook.ts` calls `REBUILD_HOOK_URL` (debounced, with retries, never failing the publish) on publish, unpublish and delete of articles and pages and on every save of the site settings, through `strapi.eventHub`; registered in `bootstrap()` and removed in `destroy()`.
