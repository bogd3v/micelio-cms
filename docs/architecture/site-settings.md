# Site settings

Moved from `CLAUDE.md` (#113).

`api::site-setting` is a single type (no draft and publish, `name` and `description` localized in `en`/`es`) with the site's identity (URL, author, logo, favicon, default OG image, social links, contact emails, Buy Me a Coffee handle), `tagline` and `addressLocality` (both localized), `timezone` (IANA name, validated against the runtime's tz data by `src/utils/site-timezone.ts`, which also fixes its case: `america/bogota` is stored as `America/Bogota`; aliases such as `EST5EDT` stay as written), `securityContact` (not localized, empty by default, at most 512 characters: one RFC 3986 `mailto:` address (optionally with `?subject=`) or `https://` URI without credentials, ASCII only, checked by `src/utils/site-security-contact.ts`, which also trims it; it becomes the `Contact` of the frontend's `/.well-known/security.txt`, RFC 9116, so **it is public**: never a private address), and `modules` (`site.modules`), the booleans the frontend uses to turn features on, all `true` by default. `theme` (`site.theme`, not localized, empty by default) picks the frontend's theme and its bounded overrides from micelio's ADR 0005: `themeId` and `defaultMode` (slugs), `accentOverrides` (`{ mode, color }` with `#RRGGBB`) and `displayFont` (curated enum). Strapi checks formats only, plus `src/utils/site-theme.ts` (a Document Service middleware) for what the schema cannot: overrides without a mode or color (`required` is not applied in a nested component) and repeated modes; the frontend resolves the theme and the accent's contrast. `populate=*` does not reach `accentOverrides`: request `populate[theme][populate]=*`. Only the frontend's custom API token reads it (`find`): `src/migrations/site-settings.ts` removes any role permission on boot, and creates neutral values («Micelio», `url` from `FRONTEND_URL`, no author or contacts) when no document exists (afterwards the admin panel owns them; the media are uploaded by hand). The code carries no values of any one site (#83): `FRONTEND_URL` is required in production (`src/utils/frontend-url.ts` stops the boot without it), `EMAIL_FROM` falls back to `no-reply@<frontend host>`, the admin CSP takes the media origin from `R2_BASE_URL`, and the fediverse plugin requires `FEDIVERSE_ACTOR_IDENTIFIER` and `FEDIVERSE_ACTOR_USERNAME`. It coexists with `global`, which the fediverse actor profile still reads.
