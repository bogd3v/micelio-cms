# Fediverse federation (ActivityPub)

**Kind:** explanation. Federation is the npm package [`@micelio/strapi-plugin-fediverse`](https://github.com/bogd3v/micelio-plugin-fediverse) (the exact version is in `package.json`); this repository, the reference distribution, installs it and keeps only the part a host provides. Before `0.7` the plugin was code here (a local plugin under `src/plugins/`); the move is in [architecture/fediverse-cut-over.md](architecture/fediverse-cut-over.md) and the upgrade in [operate/upgrade.md](operate/upgrade.md) ("Upgrading to 0.7").

## What lives in the package

Everything that makes the blog an ActivityPub actor: the actor, WebFinger, NodeInfo and the outbox, followers, likes, boosts and replies, the delivery queue and the actor key at rest, the hooks that federate an article, the Fediverse page, the article panel, the status checks and the export section, the permissions `plugin::fediverse.read` and `.manage`, its variables and its tables. Its repository has the documents:

- `docs/architecture/federation.md`: how it works, the flows, the object shape (Article or Note), the delivery retries and what a row says.
- `docs/operate/configure.md`: what a host provides, every variable, the profile, hosts and the handle, enabling federation on a running site, the Fediverse page and its diagnostics, the delivery queue, rollback.
- `docs/operate/upgrade-0.7.md`: the release notes and the upgrade.
- `docs/api.md`, `docs/security/data.md`, `docs/security/keys.md` and `docs/security/logging.md`: the public routes and the data, key and log rules of the plugin; its suites are in `test/`.
- A skill `strapi-fediverse` and an agent `fediverse` for working on it.

Read those before changing how federation works, and change them there: an issue about the plugin's behaviour belongs to that repository.

## What this repository keeps

| Part                                                              | Where                                                                                          | Why it is the host's                                                                                                                                                                                                                            |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The plugin switch                                                 | `config/plugins.ts`: `fediverse: { enabled: true }`, no `resolve`                              | Strapi bundles a plugin's admin code only while it is enabled when the admin is built, and the image builds it with `FEDIVERSE_ENABLED` unset. The package reads the variable itself: off, it is an empty plugin.                               |
| The comments extension                                            | `src/extensions/comments/strapi-server.ts`                                                     | The comments plugin is a host plugin. It adds `fediverseUri`, `fediverseActorHandle`, `fediverseNoteUri` and `fediverseNoteRetracted` (a server extension, never an extension `schema.json`: see the skill `strapi-comments`).                  |
| The comment middlewares                                           | `src/middlewares/hide-unapproved-comments.ts`, `src/middlewares/fediverse-comment-fields.ts`   | The first prunes `PENDING` and `REJECTED` comments (every fediverse reply is stored `PENDING`) and the second gives back the public fediverse fields the comments plugin's response schema drops. They protect readers while the plugin is off. |
| The rate limit group                                              | `docs/RATE_LIMITING.md` (`RATE_LIMIT_FEDIVERSE_INBOX`, federation GETs under `RATE_LIMIT_API`) | The package only calls the request guard the host registers.                                                                                                                                                                                    |
| The public counters of the response contract                      | `src/constants/response-fields/fediverse.ts`, `docs/security/response-fields.md`               | The public routes `/api/fediverse/articles/*` are in the package; the contract test of this repository pins their shape.                                                                                                                        |
| The boot migration of the header                                  | `src/migrations/fediverse-header.ts`                                                           | Moves `global.fediverseHeader` into the site's profile.                                                                                                                                                                                         |
| The token lists and grants                                        | `src/migrations/api-tokens.ts`, `src/migrations/admin-page-site.ts`                            | No grant changes for the package: its stats routes are public (`auth: false`); Editor and Author read the site on scalar fields only on an upgraded instance.                                                                                   |
| `FEDIVERSE_ENABLED`, `FEDIVERSE_ACTOR_IDENTIFIER`, `.env.example` | [operate/configure.md](operate/configure.md) ("Fediverse")                                     | The operator's interface of the image.                                                                                                                                                                                                          |

The tests that stay are `tests/fediverse-package.test.ts` (the distribution boots with the package), `tests/fediverse-disabled.test.ts`, `tests/fediverse-header-migration.test.ts`, `tests/rate-limit-fediverse.test.ts` and `tests/response-fields-fediverse.test.ts` ([architecture/testing.md](architecture/testing.md)). `npm run test:upgrade` seeds followers, an interaction, a federated article, a queued delivery, the actor key and the roles' grants in the `0.6` image and proves none is lost.
