# Fediverse federation (ActivityPub)

**Kind:** explanation. Federation is the npm package [`@micelio/strapi-plugin-fediverse`](https://github.com/bogd3v/micelio-plugin-fediverse) (the exact version is in `package.json`); this repository, the reference distribution, installs it and keeps only the part a host provides. Before `0.7` the plugin was code here (a local plugin under `src/plugins/`); the move is in [architecture/fediverse-cut-over.md](architecture/fediverse-cut-over.md) and the upgrade in [operate/upgrade.md](operate/upgrade.md) ("Upgrading to 0.7").

## What lives in the package

Everything that makes the blog an ActivityPub actor: the actor, WebFinger, NodeInfo and the outbox, followers, likes, boosts and replies, the delivery queue and the actor key at rest, the hooks that federate an article, the Fediverse page, the article panel, the status checks and the export section, the permissions `plugin::fediverse.read` and `.manage`, its variables and its tables. Its repository has the documents:

- `docs/architecture/federation.md`: how it works, the flows, the object shape (Article or Note), the delivery retries and what a row says.
- `docs/operate/configure.md`: what a host provides, every variable, the profile, hosts and the handle, enabling federation on a running site, the Fediverse page and its diagnostics, the delivery queue, rollback.
- `docs/operate/upgrade-0.7.md`: the release notes and the upgrade.
- `docs/api.md`, `docs/security/data.md`, `docs/security/keys.md` and `docs/security/logging.md`: the public routes and the data, key and log rules of the plugin; its suites are in `test/`.
- A skill `strapi-fediverse` and an agent `fediverse` for working on it.

Read those before changing how federation works, and change them there: an issue about the plugin's behaviour belongs to that repository.

## Translation credits

Who translated a locale of an article is the decision of ADR-0025 of micelio ([`docs/adr/0025-translation-credits.md`](https://github.com/bogd3v/micelio/blob/main/docs/adr/0025-translation-credits.md)), which follows [FEP-22cd](https://w3id.org/fep/22cd) (a draft). This repository holds the credits; the package publishes them from the release that implements the ADR (epic bogd3v/micelio-plugin-fediverse#40), and the two paragraphs on the package below describe that release as the ADR decides it.

**What the host holds.** `api::article.article` has `translationCredits`, a repeatable, localised and optional `shared.translation-credit` component (`src/components/shared/translation-credit.json`), at most 10 per locale. Each credit has one attribute, `actorUrl`: required, at most 255 characters, matching `^https://\S+$`. Each locale keeps its own credits and publishes them with its own content. Strapi refuses a locale whose credits break `required`, `regex` or the limit of 10 when it is published, not while it is a draft, and refuses an `actorUrl` longer than 255 characters on every save. The field's description in the admin says that the value is the translator's ActivityPub actor id and not the profile page, that it is published to the fediverse, and that unreviewed machine output credits the software's actor and not a person alone. A credit is checked by its syntax only: the CMS never requests a credited URL ([security/outbound.md](security/outbound.md)). The value is Public: an editor publishes it on purpose, with the agreement of the person it names ([security/data.md](security/data.md)). `tests/translation-credits.test.ts` covers the attribute.

**What the package reads.** The populated `translationCredits` of each published locale, only when the host's article type has the attribute, so the attribute is optional for a host. The package also leaves out an actor URL that carries credentials, and it stores no copy of the value.

**What the package publishes.** When `contentMap` has two or more locales, the `Article` or `Note` gains `translations`: one `Translation` for each locale of `contentMap` that has at least one usable credit, with `inLanguage` (the locale), `translator` (its credited actor URLs), `translationOfWork` (the `id` of the object) and `url` (the frontend address of that locale). A locale with no usable credit gets no entry, no `sourceUpdated` is sent, and a translator is never added to `attributedTo` (ADR-0025, sections 4 and 5). The credits reach the fediverse once this repository installs a release of the package that reads them; until then they are stored and not sent.

**What the frontend reads.** Nothing yet: a component is returned only when a query populates it, and the queries of `tests/helpers/frontend-queries.ts` do not name `translationCredits`, so no response the frontend reads changes ([security/response-fields.md](security/response-fields.md)).
