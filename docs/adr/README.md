# Architecture Decision Records

This folder records the decisions specific to `micelio-cms`, among them its exceptions to the engineering standard (section 16). Decisions about the product that span repositories live in [`micelio`](https://github.com/bogd3v/micelio/tree/main/docs/adr), and decisions about the standard and the shared tooling in [`micelio-engineering`](https://github.com/bogd3v/micelio-engineering/tree/main/docs/adr) (standard, section 12). Records are never rewritten: a decision that changes gets a new record that supersedes the old one.
